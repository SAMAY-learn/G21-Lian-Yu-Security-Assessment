# Lian_Yu — Penetration Testing Project

## 📌 Overview
This project documents my penetration testing journey through the **Lian_Yu room on TryHackMe**. It covers network reconnaissance, web enumeration, credential discovery, steganography analysis, SSH access, and privilege escalation in an authorized lab environment.

## 🎯 Objectives
- Identify exposed network services.
- Enumerate web directories and discover hidden information.
- Analyze files for concealed data using steganography techniques.
- Understand how weak credentials can lead to unauthorized access.
- Identify privilege escalation misconfigurations.
- Document security findings and recommend remediation.

## 🛠️ Tools Used
- Nmap
- Gobuster
- FTP
- Curl
- Stegseek / Steghide
- SSH
- Linux command-line utilities

## 🔍 Methodology
1. Network reconnaissance and service enumeration.
2. Web directory enumeration and source-code inspection.
3. Hidden file discovery and credential analysis.
4. Steganography investigation.
5. SSH access using recovered lab credentials.
6. Privilege escalation analysis.
7. Security findings and remediation recommendations.

## 📂 Project Contents
- **Presentation:** Detailed penetration testing report.
- **Screenshots:** Evidence of selected testing stages.
- **Remediation:** Recommendations for improving security.

## 🛡️ Key Lessons
- Avoid weak and reused passwords.
- Never store credentials in publicly accessible files or images.
- Restrict unnecessary network services.
- Apply least-privilege principles to sudo permissions.
- Keep sensitive information out of public repositories.

## ⚠️ Disclaimer
This project is for educational purposes and documents activity performed in an authorized TryHackMe lab. Never test systems without explicit permission.
